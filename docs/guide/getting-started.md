# Getting started

Arcanum is a free, open-source tabletop card game. You play games against the computer, against other players
online, or with friends on one device. The game handles the routine parts for you: it passes priority when you
have nothing to do, pays mana for you (unless you ask to choose), and deals combat damage.

Arcanum ships no card content. To play with real cards you also need a content module (see below).

## Install the game

Download the game from the project's releases page on GitHub. Each release has two zips:

- `Arcanum-vX.Y.Z-linux.zip` for Linux
- `Arcanum-vX.Y.Z-windows.zip` for Windows

Unzip the file into a folder of your choice and start the game from that folder.

The game checks for a newer version when it starts (see [Settings](settings.md)). If it can't update itself, it
opens the release page for you.

## Install a content module

The content module holds the card data, the card rules, the formats, the sample decks and the career's store.
Without one, the game runs with a small set of generic demo cards, and Draft, Sealed and Career are not available.

To install a module:

1. Download the module's zip from its releases page.
2. In the game, open **Extras** from the main menu.
3. Click **Install module from zip…** and choose the zip.
4. Restart the game when it asks.

The module is installed into the game's own folder. Later module updates are offered at start, like game updates.

When the game starts with a module, it downloads the card data on first start. The progress shows as
"Downloading card data… %". Card images are downloaded as they are needed. The game needs a connection for this.

**Extras** also has **Download card data again**, which fetches the card data on the next start, and the module's
name, version and license.

## First start

The first time you start the game, a **Welcome to Arcanum** dialog asks for your name. Other players see this name
online, and the first seat on this device uses it. You can change it later in [Settings](settings.md).

## The main menu

Use the mouse, or the arrow keys and Enter. Esc goes back from a submenu.

| Item | What it is |
|------|------------|
| **Play** | Start a game against the computer or on one device: constructed formats, Commander, Draft or Sealed. See [Playing](playing.md) and [Limited](limited.md). |
| **Career** | Your life as a card player: daily matches, boosters, a collection and a store. See [Career](career.md). |
| **Online** | Host a game or join one. See [Online](online.md). |
| **Decks** | Build, import and export decks. See [Decks](decks.md). |
| **Settings** | Gameplay, appearance, audio and video. See [Settings](settings.md). |
| **Extras** | Sandbox (a prepared board for trying rules), card data and the module, and the about page. |
| **Quit** | Closes the game. Not shown on mobile. |

If you left an online game that has not finished, the menu asks whether you want to get back into it.
