## What's new
- **Updates**: when the game starts it looks for a newer release and offers to install it (Update, Later or Skip this version); it downloads the new version, closes, installs it and starts again. A newer card content module is offered the same way. Settings → Gameplay → Updates turns the check off.
- **Attacking several players**: choosing another player no longer moves the creatures already attacking; it's where creatures you pick from then on go. A stack of identical tokens asks how many attack the chosen player, counting only the ones free or already attacking that player.
- **Triggered abilities to order** (and other options) are listed in one column that scrolls.
- **Foil shine** setting (Settings → Appearance): how strongly foil cards shine; softer by default so rules text stays readable.
- With three or more players your own cards keep their 1v1 size; only the opponents' areas use smaller cards.

## Install
1. Download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder). From this version on, the game updates itself.
2. Get the content module: download `arcanum-classic-v0.4.0.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest and, in Arcanum, open **Extras → Install module from zip…** (skip this if you already have 0.4.0).
3. The first start after installing or updating the module downloads the card data (a few minutes).
