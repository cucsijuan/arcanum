## What's new
- **A search language for every card search box** (deck builders, the career's cards and sell page, naming a card in a game). Loose words search names; keywords search the rest: `t:goblin` type, `o:"draw a card"` rules text, `c:rg` / `id:esper` colors and color identity, `m:2WW` mana cost, `mv<=3`, `pow>=4`, `r>=rare`, `s:` set, `f:commander`, `is:commander`, and more. Combine them with `or`, parentheses and `-` to negate; `!"name"` finds an exact name. Hover a search box for the full list; terms the game can't use are ignored and the box says why.
- **Career: selling a card one of your decks uses asks first.** Spare copies no deck needs still sell straight away, and "Sell extras" keeps what your decks use.
- **Career: four more regulars at the store** (with module 0.9.3), so ante matches and event tables vary more.

## Install
1. If you have 0.12.1 or later, the game offers this update when it starts. Otherwise download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. Get the content module: download `arcanum-classic-v0.9.3.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest and, in Arcanum, open **Extras → Install module from zip…**. This version of the game works with module 0.9.2 or later; 0.9.3 adds the new regulars.
