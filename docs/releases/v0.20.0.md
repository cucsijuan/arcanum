## What's new
- **A new full set** (with module 0.10.0): every card of the set and its bonus sheet plays, with its play booster as released (draft and sealed included) and five two-color decks. Many new rules came with it: stun and finality counters, tiered spells, job select, meld, Phyrexian mana, overload, ninjutsu, coin flips, extra end steps, giving permanents away and more.
- **Career: the new set is on the shelf**, its decks are in the store and in new careers, the regulars play them, and the store sells the set's **Starter Kit**: two 60-card decks built to play against each other, sold together.
- Cards that are only the melded half of two cards no longer show up in searches, the collection or the deck builders.

## Install
1. If you have 0.12.1 or later, the game offers this update when it starts. Otherwise download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. Get the content module: download `arcanum-classic-v0.10.0.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest and, in Arcanum, open **Extras → Install module from zip…**. This version of the game needs module 0.10.0 or later for the new set; the first start after installing downloads the card data again (a few minutes).
