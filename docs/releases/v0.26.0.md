## What's new
- **Discord activity**: while the Discord app is open on this computer, your Discord profile shows what you are doing in the game. On the menus it shows the screen you are on: choosing a game, the deck builder, draft or sealed, the online lobby with how many seats are filled, or the career. During a game it shows the kind of game (commander, versus the computer, online, a career event), the turn (or the mulligan), how many players are at the table and how long the game has run. No sign-in is needed. Turn it off in Settings → Gameplay → Online → "Show activity on Discord".
- **Player guide and wiki**: a player guide and a project wiki that mirrors the docs: the guide, the developer docs and the release notes.

## Install
1. If you have 0.12.1 or later, the game offers this update when it starts. Otherwise download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. Content module: `arcanum-classic-v0.14.0.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest (Extras → Install module from zip…), if you don't have it yet.
