## What's new
- **Career: a daily draft.** Every day the store runs a cheap draft (entry $1.00, the store provides the boosters and the drafted cards are yours); two wins or more pay a booster of the featured set.
- **Career: ten ante matches a day** instead of three.
- **Career: the week's challenges fit the new days**, among them playing the daily draft.
- Prizes of one booster read in the singular.

## Install
1. If you have 0.12.1 or later, the game offers this update when it starts. Otherwise download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. Get the content module: download `arcanum-classic-v0.9.2.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest and, in Arcanum, open **Extras → Install module from zip…**. This version of the game needs module 0.9.2 or later (the card data downloads again the first time).
