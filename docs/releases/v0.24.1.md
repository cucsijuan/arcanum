## What's new
- **Career decks in every format**: the deck desk's deck kind is now a format picker (casual, standard, pioneer, modern, legacy, vintage, pauper, Commander); the deck is checked against its format and its suggestions come from decks of that format.
- **Deck desk layout**: the deck's columns always fit the mat (they no longer drift off it when switching between Commander and other formats), the commander hint stays inside its column, and the mat is a little larger.

## Install
1. If you have 0.12.1 or later, the game offers this update when it starts. Otherwise download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. Content module: `arcanum-classic-v0.13.0.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest (Extras → Install module from zip…), if you don't have it yet.
