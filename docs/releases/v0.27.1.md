## What's new
- **Collector Boosters look like themselves**: each Collector Booster (and Set Booster) opens from its own pack, not the set's regular one.
- **Collector Booster odds as published**: a set's Collector Boosters now give each special treatment at its official odds, and their surge foils now come out as surge foils.

## Install
1. If you have 0.12.1 or later, the game offers this update when it starts. Otherwise download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. Content module: `arcanum-classic-v0.15.1.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest (Extras → Install module from zip…), for the Collector Booster fixes. This version of the game is needed for it.
