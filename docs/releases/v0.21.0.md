## What's new
- **Career: the store's website has a forum.** Practice, ante and events now live in one place, laid out like a forum dressed up as a game table:
  - **Events**: a pinned post with the coming week (each date, its events and their details), and a **[TODAY!]** post for each of today's events, where you register and go to the store.
  - **Match offers**: the regulars post when they want a game. Ante offers (one for each ante match you have left today, drawn again after each match) and practice offers (always there). Open a post and **Contact** the player: the ante chat as before, or a short chat before a practice game.
- The deck picker in every career page starts on a deck you can play.

## Install
1. If you have 0.12.1 or later, the game offers this update when it starts. Otherwise download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. Content module: `arcanum-classic-v0.10.1.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest (Extras → Install module from zip…) adds the regulars' forum posts; with 0.10.0 the forum works with plainer posts. The first start after installing it downloads the card data again (a few minutes).
