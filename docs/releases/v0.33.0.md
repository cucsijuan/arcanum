## What's new
- **Every `is:` search value**:
  - The land cycle nicknames and their other names (`is:karoo`, `is:snarl`, `is:triome`, `is:canland`...), `is:bear`, `is:commander`, `is:partner`, `is:etb`, `is:spikey`, `is:historic`, `is:atypical` / `is:default`, `is:spotlight` and the other curated values now find exactly the cards the card data's source lists for them.
  - Every promo kind the printings have works as `is:` (`is:prerelease`, `is:serialized`, `is:universesbeyond` or `is:ub`, the kind naming the story a crossover card comes from...); underscores are ignored (`is:promo_pack`).
  - `is:old` and `is:new` (card frames), `is:masterpiece`, `is:printedname`, `is:flavorname`, `is:tombstone`, `is:extended`, `is:doublesided`.

## Install
1. If you have 0.12.1 or later, the game offers this update when it starts. Otherwise download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. Update the content module too: `arcanum-classic-v0.20.0.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest (Extras → Install module from zip…); it brings the lists behind the curated `is:` values.
3. The first start after updating downloads the card data again (a few minutes), to import the printed and flavor names.
