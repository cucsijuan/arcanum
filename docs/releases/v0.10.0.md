## What's new
- **New look**: menus and dialogs wear gold frames over the colors of the nebula. Every button shares one bevelled frame, the choice to make is highlighted, and frames keep their corners whole at any size.
- **Main menu**: large options with a selector that glides to the one under the pointer (or chosen with the arrow keys), trailing faint stars.
- **Settings**: tabs along the top (Q and E switch them), options in a column with on/off switches, sliders and choices between arrows, and the description of the option under the pointer beside them.
- **Dialogs** that ask for a choice (keep or mulligan, passing a step, letting an opponent's action happen) are framed modals whose answers are plain text, the default one in gold.
- Scroll bars, drop-down lists and text fields match the rest. The phase bar keeps its plain look.

## Install
1. Download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. Get the content module: download `arcanum-classic-v0.3.0.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest and, in Arcanum, open **Extras → Install module from zip…** (skip this if you already have 0.3.0).
3. The first start after installing or updating the module downloads the card data (a few minutes).
