## What's new
- **Surge foils look like their foil paper**: soft rainbow streaks running diagonally across the card at slightly different angles, crossing and merging; their colors turn as you move the pointer over the card, as tilting it would.

## Install
1. If you have 0.12.1 or later, the game offers this update when it starts. Otherwise download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. The content module stays the same: `arcanum-classic-v0.9.1.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest (Extras → Install module from zip…) if you don't have it yet.
