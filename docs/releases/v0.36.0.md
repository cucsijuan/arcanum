## What's new
- **Game modes**: plugins that add rules to a game: deck rules, game settings (life, hand size, lands per turn, mulligan, first draw), an emblem for each player with abilities, and actions at fixed points of the game. Modes appear in the Play menu. You can add your own in the `modes/` folder of the game's user folder. Online, the host sends the mode to the players who join and runs it. Three example modes come with the game: Life Race, Overflow and Sudden Death. The guide to writing modes is game-modes in the docs.
- **Online career events**: draft events marked online can be entered online. Check in before one of the event's start times. The career service seats everyone who checked in at tables, the computer takes the empty seats, and one player at each table hosts it while the others join automatically. A result counts when the host's report and the player's report agree. Online tables with other people pay the full prizes. Playing the same event against the computer pays a share. The first one is the Online draft night, on Thursdays from November 5.
- **Career checked by the career service**: when signed in with Discord, the career service checks the career after each change, with the same rules as the game. Online events need a checked career. Careers started before this version are taken as they are the first time. The career page shows where the career stands, and offers to go back to the checked career if this one has gone apart from it.
- **Online standings**: a Standings page on the store's website, with a rank from matches against people and this month's points.
- **Online lobbies**: a lobby with a game mode shows the mode's rules. Hosting is refused for a number of players the mode does not allow.
- **Fixes**:
  - An online event's result paid the share for playing against the computer, even when it was played online.

## Install
1. If you have 0.12.1 or later, the game offers this update when it starts. Otherwise download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. The content module stays 0.22.0. If you have it, no update is needed. Otherwise install `arcanum-classic-v0.22.0.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest (Extras → Install module from zip…).
3. The first start after updating may take a moment to refresh the card data.
