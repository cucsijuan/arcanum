## What's new
- **Internet play on the console**: the console can host and join internet games through the game's own service. Sign in with Discord as on the computer. Games between computers work as before.
- **Port forwarding**: when the router can't be set up automatically, the host is told which port to forward.
- **Faster on slow devices**: the career and its screens, the play screen, the start of a game and the menu load much faster.
- **No more freezes**: cloud sync and sign-in no longer freeze the screen while they run.

## Install
1. If you have 0.12.1 or later, the game offers this update when it starts. Otherwise download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. This version needs the content module 0.28.0. The game offers it when it starts. You can also install `arcanum-classic-v0.28.0.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest (Extras → Install module from zip…).
3. The first start after updating may take a moment to refresh the card data.
