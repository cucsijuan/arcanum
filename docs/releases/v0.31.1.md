## What's new
- **Discord activity**: the activity on Discord says more about what the player is doing.
  - A game shows its format or event, with the round ("Draft match · Round 3", "<event> · Quarterfinals"), or the game number on a career commander night ("<event> · game 2 of 4").
  - A game shows "Mulligan phase" before the first turn, then "Turn N · Life N".
  - The career screens say what the player is doing: in their room, looking at the PC, at the LGS, building a deck, browsing cards, or the event's name.
  - The player count is gone.

## Install
1. If you have 0.12.1 or later, the game offers this update when it starts. Otherwise download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. The content module stays the same: `arcanum-classic-v0.19.0.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest (Extras → Install module from zip…) if you don't have it yet.
