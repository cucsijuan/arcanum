## What's new
- **Controller play on the table**: a card shows its preview while it has the focus. B puts the preview away, and one press of A plays the card or uses it. The focused card in hand lifts to the front. The life boxes and the cards of an opened zone can be reached with the arrows. Tapped cards are shown turned. The arrows prefer the card in the same row over one on a diagonal.
- **Faster start**: the module zip brings its card data already made, so cards are ready in seconds. Cards that are not ready are made when first asked for.
- **Module install**: module zips next to the game are offered for install when the game starts, before the cards load. Installing a module is faster, and the progress is shown. A failed card data download says so, and the request is tried again while the network comes up.
- **Booster pack opening**: the pack faces front until the pointer moves over it. With the controller, the pack leans with the stick or the arrows.
- **Fixes**:
  - Backing out of a spell's mana payment now leaves untapped the creatures or artifacts that would have been tapped to help pay it. They are tapped once the mana is paid.
  - The cast choice for an Omen half of a card now reads Omen.

## Install
1. If you have 0.12.1 or later, the game offers this update when it starts. Otherwise download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. This version needs the content module 0.26.1: install `arcanum-classic-v0.26.1.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest (Extras → Install module from zip…). From 0.26.1 on, the game looks for the module's own updates by itself (the module says where they are), so later module versions are offered when the game starts.
3. The first start after updating may take a moment to refresh the card data.
