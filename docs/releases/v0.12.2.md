## What's new
- **Animated menu backdrop**: a slowly drifting nebula, twinkling stars, an occasional shooting star and a faint circle of Elder Futhark runes turning behind the title screen's cards.
- **Finer buttons**: thinner gold frames and slightly larger button text.
- **Drop-down lists** open as a dark list edged by a thin gold line, and no longer grow as wide as their longest item.
- **Set filter search** (deck builder): the set list opens right below the filter with a search box; type a set code (`hoc`), words of its name (`hobbit eternal`) or letters in order.

## Install
1. If you have 0.12.1 or later, the game offers this update when it starts. Otherwise download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. The content module stays `arcanum-classic` 0.4.0 (https://github.com/cucsijuan/arcanum-classic/releases/latest); install it from **Extras → Install module from zip…** if you don't have it yet.
