## What's new
- **Play gathers every mode**: choose the mode at the top of the Play screen (each constructed format, commander, draft or sealed). A format offers only your decks that are legal in it, and its rules govern the game; draft and sealed are set up right there (boosters, table, matches), and an unfinished event is offered there to be continued or abandoned. The main menu's Limited entry is gone.
- **Online, host or join**: Online opens a small menu: hosting shows only how to set up your lobby; joining shows the invite code and address fields with the open lobbies under them.
- **Your deck is chosen in the lobby**, among your decks legal in its format; the one you used last is chosen for you as you come in.
- **Your name** is asked the first time the game starts, and can be changed in Settings.
- **Getting back into a game**: if you dropped out of an online game, or the game closed, it is offered back in a dialog when the game starts or the online screen opens ("Not now" stops asking). Joining the same place again also gets your seat back, from the computer or the countdown; when that game is over, you join the new lobby as a new player.
- **Fix**: changing your deck in the lobby just as the host starts the game no longer drops you from the game.

## Install
1. If you have 0.12.1 or later, the game offers this update when it starts. Otherwise download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. Get the content module: download `arcanum-classic-v0.7.0.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest and, in Arcanum, open **Extras → Install module from zip…**. This version of the game needs module 0.7.0 or later.
