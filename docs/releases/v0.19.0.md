## What's new
- **Five more preconstructed Commander decks** in the content module, one for each color, every card playable. They're also sold in the career store and come to commander night.
- **Many new rules** for their cards: escalate, improvise, myriad, discover, read ahead Sagas, proliferate, imprint, gifts of a card (permanents give theirs as they enter), alternative costs that tap creatures, casting from the top of the library, keeping unspent mana, reselecting what an attacker attacks, and much more.
- Improvise asks again if the artifacts you chose are needed for the rest of the cost.

## Install
1. If you have 0.12.1 or later, the game offers this update when it starts. Otherwise download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. Get the content module: download `arcanum-classic-v0.9.0.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest and, in Arcanum, open **Extras → Install module from zip…**. This version of the game needs module 0.9.0 or later (the card data downloads again the first time).
