## What's new
- **Career and game updates**: the career notes which version of the game each action was played with. Actions played offline with the previous version, and checked by the career service after updating, count as that version computed them, even when the new version's rules would give something different (for example the cards of a booster). The career keeps playing as it was across updates.
- **Updating the game**: when the career has actions the career service hasn't checked yet, the update says so and checks them before downloading.

## Install
1. If you have 0.12.1 or later, the game offers this update when it starts. Otherwise download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. The content module stays 0.22.0. If you have it, no update is needed. Otherwise install `arcanum-classic-v0.22.0.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest (Extras → Install module from zip…).
3. The first start after updating may take a moment to refresh the card data.
