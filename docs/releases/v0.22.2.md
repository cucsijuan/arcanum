## What's new
- **Online games no longer drop after about an hour**: the online sign-in renews itself every hour; when a renewal failed, messages to the other player were lost and the game disconnected. Now it retries for a few minutes and keeps the messages until it's signed in again. Both players need this version.
- Less work redrawing the players' panels during a game.

## Install
1. If you have 0.12.1 or later, the game offers this update when it starts. Otherwise download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. Content module: `arcanum-classic-v0.11.0.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest (Extras → Install module from zip…), if you don't have it yet.
