## What's new
- **Cloud saves keep working in long sessions.** The online sign-in lasts an hour and is renewed in the background; when that renewal was missed (for example after the computer slept), reading or saving the career failed with "InvalidAuth". The game now signs in again and retries.
- **Settings → Video → Window size**: pick the window's size (common 16:9 and 16:10 sizes that fit your screen). It applies at start and when changed, centered; the game scales to any size. Fullscreen still uses the screen's own resolution.

## Install
1. If you have 0.12.1 or later, the game offers this update when it starts. Otherwise download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. Content module: `arcanum-classic-v0.10.0.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest (Extras → Install module from zip…), if you don't have it yet.
