## What's new
- **Foil cards**: foil is now a finish of a printing instead of separate cards. In the deck builder, press a line's set and tick **Foil ✦** (printings that were made in foil are marked ✦). Foil copies shine under the pointer, a rainbow sheen that follows it across the card, and the large preview shines along with the card you hover. Opponents in online games see your foils too.
- Printings made only in foil are no longer offered: their pictures showed the foil, which the game now draws itself.
- Deck lines are simpler: click a line to add a copy, right-click to take one away; the printing (with ✦ when foil) opens the printings and finish menu. Deck lists mark foil lines with `*F*`, as deck sites do.
- The first start after updating imports the card data again (a few minutes).

## Install
1. Download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. Get the content module: download `arcanum-classic-v0.3.0.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest and, in Arcanum, open **Extras → Install module from zip…** (skip this if you already have 0.3.0).
3. The first start after installing or updating the module downloads the card data (a few minutes).
