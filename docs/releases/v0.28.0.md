## What's new
- **The circuit begins (career)**: a regional qualifier on the first weekend of every month, played over three days, and a regional championship once a quarter, by invitation only. The qualifier's winner is invited to the next championship.
- **Big tournaments, as they are run**: attendance that changes from one event to the next, Swiss rounds by attendance, real tiebreakers, a cut after day 1 and a top 8 playoff. Play the rounds on any day of the event; a round left unplayed when the event ends is lost.
- **Round clock**: Swiss rounds have a time limit. When time runs out, no new game begins, and a game in progress gets five more turns before it is a draw.
- **Tournament table and broadcast look**: the championship is played at its own table on one shared mat with the event's crest, and tournament games show the round clock and each player's record on screen.
- **Dropping out** of an event now keeps your place in the final standings.

## Install
1. If you have 0.12.1 or later, the game offers this update when it starts. Otherwise download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. Content module: `arcanum-classic-v0.16.0.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest (Extras → Install module from zip…), for the new tournaments. This version of the game is needed for it.
