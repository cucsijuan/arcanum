## What's new
- **Core Set 2019**: the whole set plays by its rules, with its boosters for draft and sealed and five two-color sample decks. It needs the content module 0.5.0.
- **Double-faced cards that transform**: they're cast front face up and turn over on the battlefield while staying the same permanent (counters, damage, Auras and tapped state stay). They can enter transformed, copies copy the face that's up, and the back face's mana value is the front face's. On the board you see the face that's up; hover a card and press **F** to look at its other face.
- **New rules**: state triggers, Auras that make a creature a copy of a chosen one, "can't have counters", damage that can't be prevented, creatures that can block an additional attacker or attack despite defender, casting spells or playing lands from the graveyard for a turn, ignoring hexproof for a turn, "for each player, choose target permanent that player controls", and triggers for being dealt damage, being discarded by an opponent and becoming the target of an opponent's spell.
- **Fixes**: emblems' "at the beginning of your upkeep / combat / end step" abilities now trigger, and "choose a nonbasic land card name" offers only those names.

## Install
1. If you have 0.12.1 or later, the game offers this update when it starts. Otherwise download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. Get the content module: download `arcanum-classic-v0.5.0.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest and, in Arcanum, open **Extras → Install module from zip…**. This version of the game needs module 0.5.0 or later, and module 0.5.0 needs this version of the game.
3. The first start after updating downloads the card data again (a few minutes), so double-faced cards get both faces.
