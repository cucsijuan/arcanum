## What's new
- **Opening boosters**: at the start of each draft round your booster appears in 3D, wearing the set's own pack picture. Swipe across its tear line to rip the top off and watch the cards fly out to the pick screen and turn over. If you leave it alone it opens by itself; **Settings → Play → Opening boosters** can open it automatically or skip the animation. In online drafts the first pick of each round gets extra time for it.
- **Abandon an event at any stage**: drafting, building your deck or playing the rounds, from the button at the top of the Limited screen (online, it leaves the event). Coming into Limited from the main menu with an event left unfinished now shows what it is and how far it got, to continue it or start a new one.
- **Target arrows**: arrows are beams of energy with a luminous band, a flickering glow and a barbed head, with a pulse running toward what they point at. Arrows to targets are electric blue.
- **Card backs from the content module**: the module can offer card back designs; the Classic module offers the classic Magic back (**Settings → Card back → Design**). It is downloaded the first time it's shown.
- **Godot 4.7.2**: the game is built with Godot 4.7.2.

## Install
1. If you have 0.12.1 or later, the game offers this update when it starts. Otherwise download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. Get the content module 0.6.0: download `arcanum-classic-v0.6.0.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest and, in Arcanum, open **Extras → Install module from zip…**. It brings the pack pictures and the classic card back; this version of the game also works with module 0.5.0, without them.
3. The first start after installing the new module downloads the card data again (a few minutes).
