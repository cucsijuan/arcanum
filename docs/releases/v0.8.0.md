## What's new
- **Internet lobbies**: hosted games and draft/sealed events are listed online, not only on your network. Find them in **Open lobbies** on the Online screen or join with the host's **invite code**: no addresses, port forwarding or accounts needed (players connect directly when possible, through relays otherwise). Lobbies on your own network still show up too.
- **New icon** for the game and the Windows executable.
- The license now allows linking with the online services SDK (see `LICENSE-EXCEPTION`).

## Install
1. Download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. Get the content module: download `arcanum-classic-v0.3.0.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest and, in Arcanum, open **Extras → Install module from zip…** (skip this if you already have 0.3.0).
3. The first start after installing or updating the module downloads the card data (a few minutes).
