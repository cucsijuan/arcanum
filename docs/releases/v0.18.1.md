## What's new
- **New trigger**: "whenever this creature deals combat damage to a player or planeswalker", also when an Equipment or Aura grants it.
- **More playable cards** in the content module, among them a mana rock that adds the colors your opponents' lands could make.

## Install
1. If you have 0.12.1 or later, the game offers this update when it starts. Otherwise download the zip for your system and extract it (keep the executable next to its `data_Arcanum_…` folder).
2. Get the content module: download `arcanum-classic-v0.8.1.zip` from https://github.com/cucsijuan/arcanum-classic/releases/latest and, in Arcanum, open **Extras → Install module from zip…**. This version of the game needs module 0.8.1 or later (the card data downloads again the first time).
